# flea-port

Objective: make filefinder-tui look and work like flea (`thisisgm/flea`, MIT): flea's own terminal interface (`src/tui/`), plus the flea GUI features the user chose that its terminal interface lacks.
Branch: `feat/flea-port` (from `main` d65ad1e). Delivery strategy: `exception-ok` (one commit per work unit on the branch; push, PR and merge stay the user's decisions). Test runner: `cargo test`; lint `cargo clippy --all-targets -- -D warnings`; format `cargo fmt --check`. Toolchain: `export PATH="$(brew --prefix rustup)/bin:$PATH"`.

## Specs

Sources: flea at HEAD v0.4.2, read through `gh api repos/thisisgm/flea/contents/<path>`. Paths below are flea's. "TUI" means flea's terminal interface; "GUI" its window. Strings in quotes are flea's own English strings (`i18n/en/flea.json`) and must be reproduced verbatim. Where flea's TUI defines something, it wins over the GUI.

Leaves out the Omarchy shelf, Linux desktop integration, transparency and plugins."

No sidebar, as in flea's terminal UI; places are reached with `:`."

### Screen (TUI `src/tui/layout.rs`, `render.rs`, `cells.rs`, `pane.rs`)

- **S4 Frame.** Row 1 header; row 2 a rule; rows 3..`lines-2` the body; row `lines-1` a rule; row `lines` the footer (4 chrome rows). Rules are `─` in the border colour, with `┬` (top) and `┴` (bottom) junctions at x=`left` and, when the preview shows, x=`left+middle+1`. Below 12 columns or 5 rows the screen shows only "Make the window at least 12 columns wide and 5 rows tall." (word-wrapped, centred vertically).
- **S5 Header.** One blank cell each side. Left: the path, `$HOME` shown as `~`; the parent part in the meta colour, the last component in foreground; too long → the parent is cut with `…` then `/`, the name kept. Right: the sort label in meta — `"Name"`, `"Size"`, `"Modified"`, `"Kind"` — a space, then `▴` ascending or `▾` reversed. Tabs (S20) sit between them, then the view buttons (S34), then the sort label. No back/up buttons.
- **S6 Panes.** `left = cols*22/100 - 1`; `middle = cols*40/100 - 1` with the preview, else `cols - left - 1`; `right = cols - left - middle - 2`; `│` in the border colour between them. **The left pane is flea's places panel (S33), not the parent folder's listing** (changed by L23/L24). Alt+P hides or shows the preview pane; Ctrl+B hides or shows the places panel (the list takes its room). The preview pane has 1 cell of padding each side once it is at least 7 wide.
- **S7 List rows.** Left to right: an edge cell — accent `▎` on the cursor row when the list has focus (256-colour/truecolor), else a space; the icon glyph and a space (glyph in meta, foreground on cursor/marked rows); the name cut with `…`, then in meta ` → <target>` for a symlink or ` <folder>` for a search result; the detail column `" " + value + "  "` (dropped when it doesn't fit). Text colour, first match wins: unreadable → muted; cursor or marked → foreground; symlink → `#94e2d5`; any x bit → `#a6e3a1`; everything else including folders → foreground. Fill: focused cursor row → cursor; unfocused cursor → selected; marked → marked; else none. In 16-colour/NO_COLOR the cursor row is reverse video and marked rows (NO_COLOR) underlined. Filter/find matches in the name are **bold**.
- **S8 Glyphs** (changed by L26: flea's TUI Codicons were too faint). Filled Nerd Font Material Design glyphs, verified against the installed Nerd Font: folder U+F024B, file U+F0214, text U+F0219, link to folder U+F19EE, link to file U+F1177, program U+F08C6, settings files U+F107B, image U+F021F, video U+F022B, audio U+F0223, archive U+F05C4, pdf U+F0226, language glyphs for rs/py/md/js/ts/json/shells/c/cpp/go/html/css/lua; places home U+F02DC, desktop U+F0379, documents U+F0C82, downloads U+F024D, music U+F1359, pictures U+F024F, movies U+F0381, projects U+F00D6, trash U+F0A79, drive U+F02CA; view buttons list U+F0572, columns U+F056D, grid U+F0570, two panes U+F0BCC. Each glyph takes its kind's colour from the tag palette: folders blue, pictures purple, video and PDF red, audio yellow, archives orange, code green, links the symlink colour, programs the executable colour, other files muted. Plain fallback (`FILEFINDER_ICONS=plain`): `›` for folders, a space for files.
- **S9 Detail column.** `I` cycles Size → Modified → Mode → Owner → Size, posting "Detail column · Size" etc. Mode is shown the way `ls -l` writes it, `drwx------`, not flea's octal `0755`: the user asked for that column earlier ("in the list view, add a new column with the permissions like drwx-------"), see L8. Folder sizes are item counts here (flea computes recursive sizes; see A2).
- **S10 Preview pane.** Row 0: icon and **bold** name (` → target` in meta for links); row 1: `Kind · Size · Date` in meta (folders `"Folder"`); row 2 blank; body from row 3. Folder → its children as quiet rows with sizes. Text → right-aligned line-number gutter in meta, a space, the text, long lines wrapped. Archive → entry rows, then `"+ N more"`. Image → the picture (kitty / sixel / half-blocks through the existing ratatui-image code), a blank row, then up to 3 facts `Label · value` (labels `"Pixels"`, `"Size"`, `"Kind"`…). Several marked → `"N items selected"`, `"Combined · SIZE"`, then the marked rows. Unreadable folder → centred lock glyph U+EA75 in the error colour and the reason.
- **S11 Footer.** One space, left runs, padding, right runs, one space. Left: `"N items"`, or `"K of N selected · SIZE"`; with a filter muted `"Filter q"` then `"N of M shown"`; during find `"N found"` / `"N found · M scanned"`; notices in foreground followed by muted `"· z undoes"` after an undoable change; errors in the error colour. Right: `"<fs> · X free"` (fs = the volume's file-system type, e.g. `apfs`), a muted `·`, muted `"? keys"`; each dropped when it doesn't fit. Notices last 4 s; errors and undo receipts 8 s; Escape dismisses an error. Receipts: `"Moved N items to Trash"`, `"Copied N items"`, `"Renamed"`, `"Folder created"`, `"Undid %1"`, `"Nothing to paste"`.
- **S12 Empty and no-match.** Empty folder: a centred glyph and a caption rotating every 2.8 s through `"NOTHING HERE YET"`, `"A VERY TIDY FOLDER"`, `"QUIET IN HERE"`. No filter match: centred U+EA6D over `"NOTHING MATCHES q"`.
- **S13 Colours** (TUI `theme.rs`, fallback palette — no Omarchy theme on macOS). Terminal's own background (no fill). Foreground `#cacccc`; muted/meta/frame `#909292`; selected `#313436`; cursor `#313436`; marked `#515455`; tab/menu-cursor fill `#1f2224`; match fill `#2a2d2f`; border `#26292b`; card rule `#434647`; default-button wash `#2a2d2f`; prompt field `#1d2022`; field selection `#47494b`; extension ink `#909292`; error `#b06969`; unavailable `#684243`; symlink `#94e2d5`; executable `#a6e3a1`; dimmed text behind cards `#6d7070`. Depth: `NO_COLOR` → mono; `COLORTERM` truecolor/24bit → truecolor; else 256-colour by nearest index (fg 252, muted 246, selected/cursor/match 236, marked 240, tab/border 235, rule/stem 238, field 234, symlink 116, executable 151, error 131); 16-colour as the last resort.

### Keys (TUI `keys.toml` `[[tui]]` 2723+, `keymap.rs`, `key_sheet.rs`, `actions.rs`)

- **S14 Movement.** `j`/↓ down, `k`/↑ up, `g`/Home first, `G`/End last, Ctrl+D/PageDown page down, Ctrl+U/PageUp page up, Enter open, `h`/←/Backspace parent, `l`/→ browse in, `H`/`L` back/forward, Tab focus the preview (and back), Escape "Close or go back".
- **S15 Look and find.** `?` key sheet, Space Quick Look, `.` show hidden files, `/` filter, `f`/Ctrl+F find, Ctrl+G find in contents, `o` reveal, `s` next sort, `S` reverse sort, `:`/Ctrl+L "Go to", Ctrl+R/F5 reload, Alt+P preview pane.
- **S16 Change.** `y`/Ctrl+C copy, `x`/Ctrl+X cut, `p`/Ctrl+V paste, `M` "Move here", `U` duplicate, `r`/F2 rename, `dd` or Delete move to Trash, Shift+Delete delete permanently, `z`/Ctrl+Z undo, Ctrl+Shift+Z/Ctrl+Y redo, `N`/Ctrl+Shift+N new folder, `E` edit in `$EDITOR`, `v` toggle select, `J`/`K`/Shift+↓/↑ extend, `V` invert selection, Ctrl+A select all, `m`/Menu/Shift+F10 menu, Ctrl+T terminal, Ctrl+Shift+C copy path, `Y` copy folder path, `T` tags (S22), `I` detail column.
- **S17 Tabs and quitting.** `t` new tab, `w`/Ctrl+W close tab (closing the last tab quits), `[`/`]` previous/next tab, `{`/`}` move tab left/right, `1`–`9` go to tab N, `O` open in a new tab, `q` quit. Digits are never counts.
- **S18 `dd`.** The first `d` arms and posts "Press d again to move it to Trash, or press Delete on its own." ("them" with a selection); a second `d` within 1.5 s trashes; any other key or the timeout disarms; nothing arms in an empty folder.
- **S19 Kept keys** (user's earlier requests, not flea's, kept because they collide with nothing in flea's TUI keymap): `|` and Alt+1 toggle two panes (as Ctrl+4). The previous folio keymap is otherwise replaced.

### Features

- **S20 Tabs.** The strip shows only with 2+ tabs, at most 9 ("Nine tabs is the most"); labels `" N foldername "`, the current tab on the tab fill in foreground, the others muted; the strip scrolls to keep the current tab visible. A new tab opens the current folder. `1`–`9` on a missing tab: "No tab %1". `O` on a file: "Only a folder opens in a new tab."
- **S21 Views** (GUI, added): Ctrl+1 list (the S4–S10 screen, default), Ctrl+2 columns (Miller columns with the preview), Ctrl+3 grid (thumbnails, two-line captions wrapped at space `-` `_` `.`, extension kept), Ctrl+4 two panes (each with its own path; only the focused pane draws the accent cursor; Ctrl+4 again returns to the previous view; copy/move between panes through `y`/`x`/`p` and `M`). Restyled in flea's colours and rows. **The app opens in two panes** (L28): both on the start folder, the left one with the keyboard; the remembered one-pane view (list on a first start) is what Ctrl+4 returns to, and starting saves nothing.
- **S22 Tags** (GUI, added; stored as Finder tags). Seven tags in 1–7 order: Red, Orange, Yellow, Green, Blue, Purple, Gray; colours `#f7768e`, `#eb927b`, `#e0af68`, `#9ece6a`, `#7aa2f7`, `#ad8ee6`, `#565f89`. Stored in the macOS Finder tags attribute `com.apple.metadata:_kMDItemUserTags` so Finder shows them. `T` opens a menu with the seven tags and "Remove All Tags" (only while some tag applies); `1`–`7` toggle: removed where every target already has it, else added. Shown as small coloured squares after the name in rows and grid captions. Receipts: "Tagged %1 items %2", "Removed %2 from %1 items", "Removed all tags from %1 items". Undoable. Find understands `tag:<name>` (case-insensitive; every named tag must be present).
- **S23 Filter `/`.** Narrows the current listing as you type: substring, `*`/`?` pattern, and close (typo) matches only when nothing matches exactly (typo budget 0 under 4 characters, 1 up to 7, 2 from 8). Tab switches scope between this folder and subfolders. Bottom-row prompt labelled "Filter"; footer `"N of M shown"`; Escape clears; Ctrl+A selects only what is shown.
- **S24 Find `f`.** Recursive walk; Tab cycles scope this folder → Home → everywhere; Ctrl+G toggles names/contents (contents with `rg` when installed). Prompt "Find" with `"in ~/x · tab changes scope"`. Ranking tiers: exact > prefix > word start > aligned > subsequence > typo (typo only when nothing better matches); ties to the shorter path, then natural order. Enter keeps the results and moves the keyboard into them; `o` reveals a result in its folder; Escape stops a running walk, then leaves. Footer `"N found · M scanned"`, `"Nothing matches %1"`.
- **S25 Prompts** (bottom row): muted label, a space, the field on the field fill; labels "Filter", "Find", "Go to", "Rename", "Folder name". Rename shows right-aligned muted "enter saves · esc cancels · ctrl-a selects the whole name". "Go to": Tab accepts the completion. Validation errors in the error colour (e.g. "A name cannot be empty.").
- **S26 Paste conflicts.** Status-row question "<name> already exists in <folder>." (or "N items already exist in <folder>."), two spaces, muted "enter or b keeps both · r replaces · s skips · esc cancels"; the cursor jumps to the clashing row. Keep both uses flea's " copy" / " copy 2" naming. Replace moves the existing item to the Trash first so undo can bring it back (A3).
- **S27 Bulk rename.** `r` with several items selected opens `$EDITOR` on the list of names (one per line); on save the renames run as one batch through temporary names, "Renaming %1 of %2", then "Renamed N items · Undo reverts one". Mismatched line counts or clashing names refuse with a message and rename nothing.
- **S28 Compress and extract** (menu). Compress formats in order: zip, tar, tar.gz, tar.bz2, tar.xz (plus 7z when `7zz`/`7z` is installed), progress "Compressing %1 to .%2"; Extract for zip/tar.*/7z beside the archive. Output names never overwrite: next free " copy" name (`pack copy.tar.gz`, `pack copy 2.tar.gz`). Both undoable.
- **S29 Menu `m`.** A framed box under the cursor row at the name column (above it when there is no room); rows ` glyph label`, the cursor row on the tab fill, rules between groups, submenus with muted caps titles (`"OPEN WITH"`, `"COMPRESS"`). Rows: Open, Open With ›, Compress ›, Extract, Tags ›, Copy Path, Rename, Duplicate, Move to Trash, Delete Permanently… (error colour), Show/Hide Hidden Files, Open Trash.
- **S30 Cards.** Centred, framed, `┌┐└┘` corners, 2 cells of side padding; row 1 bold title with muted "esc" at the end, row 2 a rule; buttons `[ Label ]` bottom-right, the default with the accent bracket and wash. Permanent delete: "Delete N items permanently?", body "These items are deleted from disk. This cannot be undone." (singular "This item is deleted from disk. This cannot be undone."), buttons Cancel (default) and "Delete". `?` sheet: "Keyboard Shortcuts", groups `MOVE` / `LOOK` / `FIND` / `CHANGE`, keys right-aligned in meta, scrolls.
- **S31 Quick Look** (Space). An in-terminal card inset 9 cells each side (min 24 wide) from row 3, frame colour, the rest dimmed; top row glyph, bold name, a meta fact (`"W × H"`, `"N lines"`, `"N pages"`, `"N entries"`), `×` two cells from the right; then a rule, a blank row, the body (picture or text). Esc closes; `j`/`k` move the list cursor and the card follows; `+`/`-` zoom, `0` fit.
- **S32 Mouse** (TUI `actions_pointer.rs`). Click sets the cursor and clears the selection; double click within 400 ms opens; Ctrl/Cmd click toggles; Shift click a range; right click the menu; wheel moves the cursor by 1; a click on a tab label switches tab; a click in the parent column opens that folder; clicks outside a card close it.

- **S33 Places panel** (user request L23, layout choice L24, places added by L29 and L30; flea GUI `src/ui_logic_rail_places/order.rs`, `crates/flea-gui/src/rail/rows.rs`). The left pane, in every view: dim upper-case section headings in the muted colour, empty sections draw no heading. PLACES: Applications (`/Applications`) when it exists, Home, then whichever exist of Desktop, Documents, Downloads, Music, Pictures, Movies, Projects, then Trash; DEVICES: the system's own volume (the `/Volumes` entry that links to `/`, under its own name, opening `/`), then iCloud Drive (`~/Library/Mobile Documents/com~apple~CloudDocs`) when it exists, then the other mounted volumes under `/Volumes` by name. Each row: glyph and name; the place holding the active pane's folder (deepest match) on the selected fill, with the accent `▎` edge and cursor fill when the panel has the keyboard. Tab reaches the panel; `j`/`k`/↑/↓ move, Enter or `l` opens the place and gives the keyboard to the list; a click opens it; right click on a drive is not required. Ctrl+B hides or shows the panel (remembered). The panel is read again on start, F5 and when the keyboard enters it, never per frame.
- **S34 View buttons** (user request L23; made bigger by L27). In the header, right side before the sort label: four clickable buttons for list, columns, grid and two panes, each a three-cell chip (a cell of fill, the glyph, a cell of fill), chips a cell apart, the glyph in the foreground; the current view's chip on the cursor fill, the others on the tab fill; the whole chip answers a click like Ctrl+1–4. Plain fallbacks `≡` `∥` `▦` `◫`.
- **S35 App icons** (user requests L31 and L32). An app bundle's picture (grid, preview, look) is the `.icns` file its `Info.plist` names in `CFBundleIconFile` (`.icns` added when the name has none), turned into a PNG by `sips`; never Quick Look, which can wait on an app for good. Apps that keep their icon only in an asset catalog keep the glyph. In the list, the columns and the two panes, an app's icon takes the two cells of its glyph and the space after it once ready, only where the terminal draws real pictures (not half blocks).
- **S36 Coloured code** (user request L33; flea `src/backend/codereq.rs`, `src/backend/sgr.rs`, `src/tui/syntax.rs`, `src/ui_logic_doc_preview/code.rs`). The preview's text lines (and Quick Look's) are coloured by `bat` run with flea's flags `--no-config --no-custom-assets --theme=ansi --color=always --style=plain --paging=never --wrap=never` plus `--file-name=<name>`, the shown lines given on stdin; SGR 31–36 and 91–96 become roles 1–6, 0/30/37/39/90/97 and extended foregrounds the foreground, bold and backgrounds dropped; a line keeps its colours only when they spell it; a magenta run of only `=+-*%<>!&|^~?:` is drawn in the foreground (flea's TUI). Roles in flea's fallback colours `#f38ba8 #a6e3a1 #f9e2af #89b4fa #cba6f7 #94e2d5`. Off the UI thread, one file at a time, the newest replacing one waiting; plain until ready, plain without `bat`. App icons also show in the preview, with `Kind · Application` and no size under them.
- **S37 Tags in the panel** (user request L37, Spotlight chosen in L38; flea GUI `src/ui_logic_rail_places/order.rs:166-169`, `tags.rs:6,226-233`, `window/search_tag.rs:40-46`). A TAGS section between PLACES and DEVICES lists, in Red, Orange, Yellow, Green, Blue, Purple, Gray order, only the colour tags some file carries (Spotlight counts, read at start, on F5 and after the app changes tags; none without Spotlight), each with a tag glyph in its colour. Opening one runs Find for `tag:<name>` everywhere with the keyboard in the results; its row is lifted while they show. A Find of nothing but `tag:` terms in the everywhere scope asks Spotlight (`mdfind` over the whole Mac), each found file's tags re-read before it counts, hidden items held back unless they show; in a folder or home, and without Spotlight, it walks as before (exact where Spotlight doesn't index). Enter keeps such a Find's results; none found says `NOTHING MATCHES tag:<name>`; an item that loses the tag leaves the results.
- **S38 List columns** (user request L43). In the list and the two panes, the row after the name shows the columns Size, User, Permissions, Kind, Modified, in that order, a 2-cell gap apart, under a header on the list's first row: "Name" over the names, each column's title over it, muted; the column the items are sorted by in the foreground with ` ▴`/` ▾`. Sizes line up on the right, the rest on the left. Each column is as wide as its widest value among the rows showing or its title (with room for the arrow when it sorts), up to Size 11, User 16, Permissions 10, Kind 20, Modified 16 (cut with `…`). When the list is narrow the last columns make way first, so the name keeps at least 20 cells. The columns view keeps its single detail column, which `I` still changes.
